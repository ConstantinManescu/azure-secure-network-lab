# Lab 00 — GitHub and Cost Safety

## Objective

Prepare a public GitHub repository for the Azure Secure Network Infrastructure Lab and define the cost-control workflow before deploying Azure resources.

## Completed

- Created the public GitHub repository.
- Added the initial project README.
- Installed Git and configured the local Git identity.
- Installed Visual Studio Code.
- Cloned the repository locally.
- Created the initial repository structure.

## Cost-control rule

> Deploy → Learn / Test → Capture evidence → Destroy

All Azure resources for this project will be deployed into a dedicated Resource Group and deleted after each lab session.

## Security rule

No passwords, access keys, connection strings, Subscription IDs, Tenant IDs, public IP addresses, or personal data will be committed to this repository.
